# 🏦 Банковский маркетинг: анализ клиентов и прогноз откликов

## 📌 Описание проекта
В данном проекте решается задача из **банковского сектора**, связанная с повышением эффективности маркетинговых кампаний.  
Банки собирают большие объёмы информации о своих клиентах и стремятся выбирать именно тех, кто с наибольшей вероятностью воспользуется предложением (например, откроет депозит).

Цель проекта — **проанализировать данные о маркетинговой кампании банка, выявить закономерности и построить модель, предсказывающую отклик клиента**.

---

## 🎯 Цели проекта
- Изучить данные о клиентах и их откликах на маркетинговые предложения.
- Определить ключевые характеристики, влияющие на вероятность открытия депозита.
- Сегментировать клиентов и выделить целевую аудиторию.
- Построить модель машинного обучения для прогноза, воспользуется ли клиент предложением банка.

---

## 📊 Используемые данные
В распоряжении представлены данные реального банка о последней маркетинговой кампании.  
Набор данных включает в себя:
- Социо-демографические характеристики клиентов,
- Финансовую активность,
- Историю контактов и взаимодействия с банком,
- Метку целевого признака (`deposit`), указывающую, воспользовался ли клиент предложением.

---

## 🛠 Стек технологий
- **Python 3**
- **Pandas, NumPy** — обработка и анализ данных
- **Matplotlib, Seaborn** — визуализация
- **Scikit-learn** — построение моделей машинного обучения
- **Jupyter Notebook** — исследовательский анализ данных и прототипирование

---

## 📈 Этапы работы
1. **Загрузка и предобработка данных**
   - очистка и приведение признаков к нужному виду.
2. **Разведочный анализ данных (EDA)**
   - исследование распределений, корреляций, визуализация.
3. **Сегментация клиентов**
   - выделение групп клиентов с похожими характеристиками.
4. **Построение и обучение моделей**
   - подбор лучшей модели для предсказания отклика.
5. **Интерпретация результатов**
   - выделение факторов, наиболее сильно влияющих на решение клиента.

---

## 📌 Результаты
- Определены ключевые признаки, влияющие на открытие депозита.
- Сегментированы клиенты на группы по склонности к отклику.
- Построена модель, которая прогнозирует вероятность положительного ответа на предложение банка.

---

## 🚀 Выводы и применение
Результаты проекта помогают банку:
- Сократить расходы на маркетинг, обращаясь только к наиболее перспективным клиентам.
- Повысить конверсию маркетинговых кампаний.
- Построить персонализированные предложения на основе сегментации клиентов.
